02 / LAB TOOLS

Herramientas útiles.
Ideas en movimiento.

Pequeñas utilidades interactivas para creadores, negocios y personas que quieren convertir una idea en algo tangible.

TOOL 01 / GOOGLE REVIEWS

Generador de enlace de reseñas

Introduce el Place ID de un negocio y genera un enlace directo para que sus clientes puedan dejar una reseña en Google.

El Place ID se obtiene desde las herramientas oficiales de Google Maps Platform. Esta herramienta no consulta ni verifica automáticamente el identificador.

TOOL 02 / PARAMETRIC DESIGN

Generador de llaveros

Personaliza un diseño sencillo con texto, dimensiones y orificio para anilla. Descarga el diseño vectorial SVG para seguir editándolo o prepararlo para modelado 3D.
